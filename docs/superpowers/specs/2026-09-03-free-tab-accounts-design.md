# 自由 Tab · 账户（可存可取）设计说明

> 日期：2026-09-03  
> 状态：已确认（对话审阅）  
> 需求来源：`docs/hive-需求说明.md`（本版同步升至 v0.3）  
> 原型对照：`prototypes/hive-v1/index.html`  
> 范围：需求与原型；**不含** Flutter 实现（实现另写 plan）

---

## 1. 目标与约束

### 1.1 背景

现有「梦想储蓄罐」：有目标金额、只存不取、可标记完成。用户还需一类**无目标**、可存可取的容器（教育基金、养老、备用金、旅游等），自由命名，用于灵活备用。

### 1.2 成功标准（本设计 / 原型）

- 底栏「梦想」更名为「自由」
- 同一 Tab 内两种类型：`goal` 梦想储蓄罐、`fund` 账户
- 账户：自由命名、无目标、可存可取、不可超余额、无完成态
- 存/取均与消费分账
- 原型可点击走通列表 / 新建 / 详情 / 存取

### 1.3 明确不做（本版）

- 罐子间划转
- 取出记入消费（不可选分类进年对比）
- 账户「标记完成」/ 归档
- 系统预设类别模板
- 透支（余额为负）
- Flutter 代码与 schema 迁移实现（仅在本 spec 约定模型，落地另开 plan）

---

## 2. 信息架构

底栏：**消费 | 自由**。

| 类型 | 产品名 | 心智 |
|---|---|---|
| `goal` | 梦想储蓄罐 | 有目标、只存、可标记完成 |
| `fund` | 账户 | 无目标、可存可取、无完成态 |

**自由首页**

- 类型切换：储蓄罐 | 账户
- 储蓄罐下：进行中 / 含已完成（与现有一致）
- 新建：先选类型，再进对应表单
- 储蓄罐行：名称、已存/目标、进度
- 账户行：名称、当前余额（无进度）

**详情**

- 储蓄罐：目标、已存、差额、进度、存一笔、改名/目标、标记完成、流水
- 账户：余额、存一笔、取一笔、改名、删除、流水（存/取区分）

## 3. 数据模型与规则

### 3.1 罐子（沿用 `dream_jars` 表名亦可，减少无意义改名）

| 字段 | 说明 |
|---|---|
| `kind` | `goal` \| `fund` |
| `name` | 必填，自由命名 |
| `target_cents` | `goal` 必填且 >0；`fund` 不用 |
| `status` | 仅 `goal`：`active` \| `completed`；`fund` 无完成态 |
| `description` | 可选 |
| id / created_at / family_id / member_id | 与现有一致 |

存量数据：现有罐子一律视为 `kind=goal`。

### 3.2 流水（扩展现有 deposits）

| 字段 | 说明 |
|---|---|
| `amount_cents` | 有符号：存入 >0，取出 <0 |
| `date` | YYYY-MM-DD，默认今天可改 |
| `note` | 可选 |

**余额** = 该罐子全部流水之和。

### 3.3 业务规则

1. 消费与自由完全分账：流水永不写入消费统计  
2. `goal`：只允许正数流水；不支持取出；记错则改/删该条  
3. `fund`：可正可负；取出后余额不得 <0；无标记完成；删除时若余额 ≠0 需二次确认  
4. 不做罐子间划转  
5. 账户无系统预设类别

## 4. 页面与原型

| 页面 | 变更 |
|---|---|
| 底栏 | 「梦想」→「自由」 |
| 自由首页 | 类型 chip、列表按 kind 过滤、新建分流 |
| 新建储蓄罐 | 名称 + 目标（现有） |
| 新建账户 | 仅名称 |
| 储蓄罐详情 / 存一笔 | 文案微调（存入储蓄罐） |
| 账户详情 | 新屏：余额、存/取、删除 |
| 账户存一笔 / 取一笔 | 新屏：金额、日期、备注；取出示意超额拒绝 |

样例数据：保留储蓄罐示例；增加「备用金」「教育基金」等账户及正负流水。

---

## 5. 验收标准

1. 底栏为「消费 | 自由」  
2. 自由首页可切换「储蓄罐」与「账户」  
3. 可新建储蓄罐（名称+目标）与账户（仅名称）  
4. 储蓄罐：仅存入、有进度、可标记完成；不可取出  
5. 账户：可存可取；超额取出被拒绝（原型 toast 示意）  
6. 账户无「标记完成」；可改名；删除有确认语义  
7. 文案与说明体现存/取不进消费年对比  
8. 不做划转、取出进消费、预设类别  

---

## 6. 与旧文档关系

- 原「明确不做 · 梦想取出」收窄为：**储蓄罐（goal）仍不支持取出**；**账户（fund）支持取出**。  
- 罐子间自动划转仍不做。  
- Flutter 一期 design（`2026-08-31-hive-flutter-design.md`）中「梦想取出」条目在实现本功能的 plan 中再修订；本 spec 为产品真相来源之一，以需求说明 v0.3 为准。
